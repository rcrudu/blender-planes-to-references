A simple script to change (multiple) mesh planes to reference objects for Blender3D

In the current version of Blender you can mass import images as planes but you can only import one reference image at a time. Plane textures are only visible in Solid mode although reference images are also shown in Wireframe mode. With this script you can import all your planes and then easily convert them to reference images.

To use: select the Scripting tab and import this script; select the mesh planes you want to convert to reference objects and click "Run Script" (or use Alt P).
